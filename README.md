# Windows 资源管理器图标

一个适用于 Windows 桌面版 VS Code 的文件图标主题。它通过 Windows Shell 获取文件夹图标和常见文件类型图标，在扩展安装目录里生成主题。首次启用时会提取一次，不扫描工作区文件。

## 安装与使用

1. 打开 VS Code 扩展视图，点右上角 `…` →「从 VSIX 安装…」，选择本地 `.vsix`。
2. 按 `Ctrl+Shift+P`，运行「首选项：文件图标主题」，选中「Windows 资源管理器图标」并按回车。
3. 等待首次读取完成。换了 Windows 默认应用或图标未更新时，可以运行「Windows 图标：刷新本机图标」。若界面还没变化，点击通知中的「重新加载窗口」。

可在用户设置 `windowsExplorerIcons.extraExtensions` 中添加不常见的扩展名，例如 `["xcf"]`。未注册的文件类型可能由 Windows 返回通用图标。

## 范围

VS Code 按扩展名匹配图标，无法显示每个 `.exe` 的独立图标、文件夹自定义图标、缩略图或快捷方式角标。不同电脑的文件关联不同，结果也可能不同。
